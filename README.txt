AK Smarts main website (aksmarts.com) - static site

Pages: index.html (Home), products.html, about.html, contact.html, privacy.html, terms.html
Styles: assets/style.css   Images: assets/

To publish: upload everything in this folder to the web root of aksmarts.com
(any static host works: cPanel public_html, Netlify, Cloudflare Pages, GitHub Pages, Render static site).

Before going live, search the pages for "[" and replace the yellow placeholders
that are left (next product names on products.html, legal entity name and
grievance officer details in privacy.html and terms.html).
The Privacy policy and Terms are drafts - have them checked by your lawyer or CA.
The contact form opens the visitor's email app addressed to info@aksmarts.com (no server needed).
